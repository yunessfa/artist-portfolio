# ۱. تحلیل کامل نسخه‌ی فعلی (Reverse Engineering)

این سند حاصل بازمهندسی کامل فایل `artist-portfolio.html` است. **هیچ چیزی حدس زده نشده** — همه‌ی مقادیر از دل باندل esbuild استخراج شده‌اند.

## ۱-۱. مشخصات فنی نسخه‌ی فعلی

| مورد | مقدار |
|---|---|
| نوع فایل | تک‌فایل HTML خودبسنده |
| حجم | ۶۰۴٫۹۴۸ بایت (۴۷۴ خط) |
| حجم باندل JS | ۳۸۸٫۲۰۰ کاراکتر در یک خط (خط ۴۱۳) |
| فریم‌ورک | React (باندل‌شده با esbuild، مینیفاید) |
| مدیریت استیت | `useState` / `useEffect` در یک کامپوننت ریشه |
| استایل | CSS درون‌خطی + CSS Variables |
| انیمیشن | `motion@11.18.2` از CDN |
| اسکرول | `locomotive-scroll@5.0.0-beta.21` از CDN + fallback دستی |
| فونت | Vazirmatn v33.003 از jsDelivr |
| تصاویر | ۶ تصویر WebP به صورت Base64 **درون HTML** |
| بک‌اند | ندارد — همه‌ی داده‌ها hardcoded |
| پنل مدیریت | ندارد |
| ماندگاری | فقط `localStorage` |

## ۱-۲. قابلیت‌های موجود که **حفظ شده‌اند**

- سیستم قالب سه‌بعدی: **۴ قالب × ۲ حالت روز/شب × ۴ فصل = ۳۲ حالت بصری**
- Theme Switcher زنده با ۲۱ متغیر CSS
- تشخیص خودکار فصل و روز/شب
- Gallery با فیلتر دسته‌بندی
- Lightbox با ناوبری کیبورد
- Reveal on scroll + Parallax
- ذرات محیطی فصلی (۲۶ ذره‌ی دترمینیستیک)
- اعداد فارسی، RTL کامل
- حالت QA (`?qa=1`) برای غیرفعال کردن انیمیشن‌ها

## ۱-۷. مشکلات نسخه‌ی فعلی (۱۵ مورد)

1. **تمام داده‌ها hardcoded است** — هنرمند نمی‌تواند هیچ چیزی را تغییر دهد.
2. **تصاویر Base64 درون HTML** — ۶۰۰KB در هر بازدید، بدون کش، بدون srcset.
3. **پنل مدیریت وجود ندارد.**
4. **بدون بک‌اند و دیتابیس** — فرم تماس واقعی نیست.
5. **ماندگاری قالب فقط در مرورگر** — قالب انتخابی هنرمند برای بازدیدکنندگان اعمال نمی‌شود.
6. **کامپوننت یکپارچه (monolithic)** — غیرقابل نگهداری.
7. **وابستگی به CDN خارجی** — اگر jsDelivr قطع شود، انیمیشن‌ها و فونت از کار می‌افتند.
8. **بدون مسیریابی** — هر اثر URL مختص ندارد، پس اشتراک‌گذاری و SEO ممکن نیست.
9. **بدون SEO** — نه meta اختصاصی، نه Open Graph، نه Structured Data، نه sitemap.
10. **مشکل دسترسی‌پذیری** — فوکوس در Lightbox ترپ نمی‌شود، ARIA ناقص است.
11. **بدون بهینه‌سازی تصویر** — بدون lazy loading، بدون AVIF، بدون پلیس‌هولدر.
12. **پارالاکس در جاهایی لوپ مصنوعی دارد** — حرکت مستقل از اسکرول.
13. **انیمیشن‌ها پراکنده و hardcoded** — سیستم مرکزی وجود ندارد.
14. **بدون مدیریت خطا** — نه ۴۰۴، نه حالت شبکه‌ی قطع.
15. **بدون زیرساخت چندزبانی.**
